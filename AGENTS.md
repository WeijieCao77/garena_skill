# AGENTS.md

This workspace is for a time-boxed game feature prototyping exercise.

- For any request to design, build, change or demo a game feature prototype, use the `$game-feature-prototype` skill in `.agents/skills/game-feature-prototype/`.
- Reply in Simplified Chinese unless the user writes in English. Keep replies short: what changed, how to see it, next step.
- All output goes in `prototype/`: `BRIEF.md`, `index.html`, `checkpoint-N.html`, `DEMO.md`.
- The deliverable is a single self-contained HTML file that opens by double-click on Windows. Do not install packages, start servers, or deploy.
- To preview on Windows, run `start prototype\index.html` (PowerShell: `Start-Process prototype\index.html`).
- Never delete checkpoints. If an edit breaks the page, restore the latest checkpoint and retry in a smaller step.
