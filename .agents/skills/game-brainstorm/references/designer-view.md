# Designer view

Ask these of an idea, in plain words, when they sharpen it. Don't turn the jam into a checklist.

1. **Feeling first.** Designers pick the feeling, then a mechanic that produces it (MDA: mechanics → dynamics → aesthetics). Name it as a player would: 不服、想证明自己、想和朋友一起、怕错过、终于变强了.
2. **One number up, one guardrail.**

   | Goal | Main metric | Guardrail |
   | --- | --- | --- |
   | New players stay | Day-1 / day-7 retention | Time to first match |
   | Lapsed players return | Return rate, 7-day retention after return | Fairness felt by active players |
   | Play more often | DAU, matches per player | Burnout, early quits |
   | Bring friends | Invite conversion, share rate | Spam invites, reports |
   | Spend | Payer rate, bookings per user | Refunds, pay-to-win complaints |
   | Watch esports | Watch-to-play conversion | Disruption to viewing |

3. **What next.** After the moment, what does the player get, feel, and want to do next? A feature that ends on "领取成功" has no next step.
4. **Timing is design.** The first minutes decide whether a new player stays. Give event cycles a reason: for example, a 21-day return event covers three weekends, with core tasks in days 1–7. A festival event should fit into the core loop, not sit beside it.
5. **Psychology, with limits.** Near misses (差一点就赢), match-to-match variety and a high skill ceiling drive "one more match". Small first purchases and virtual currency make spending easier. Know where that stops being fair, and have one sentence on spending pressure and minors.
6. **Publisher view.** Garena publishes and operates games outside mainland China. Ask whether the feature can run in a real market: localization, creators and esports, cost per player, and operations load.

## What interviewers push on

From candidate interview notes (anecdotal): how a game they play makes money, how its live operations work, how to turn a single-player game into a live game (selling point, players who dislike the change, revenue effect), and how to market a game. One rejected candidate was told nothing in the answers made the interviewer light up.

Explain a decision as: "我选了 X，因为 Y；上线后看 Z，如果 Z 不好，说明……"
